# Intelligent Doc Parser (Llama 4) 🚀

A simple but powerful document extractor using **Groq's Llama 4 Scout**.

## 🛠 Setup
1. **Backend**: `pip install -r requirements.txt` -> `python src/backendCode.py`
2. **Frontend**: `npm install` -> `npm run dev`
3. **API Key**: Add your `GROQ_API_KEY` to the `.env` file.

## ✨ Current Features
- Instant JSON extraction from PDFs and Images.
- High-speed inference via Llama 4 Scout (17B-16E).
- Clean dark-mode UI with drag-and-drop.

## 🔮 Future Roadmap
- **Chat-with-Doc**: Talk to your documents like a chatbot (ask specific questions).
- **History**: Save and search through previous uploads.
- **Export**: Download results as Excel/CSV.
- **Multi-page Support**: Handle large documents with RAG.
